# Changelog — Mosquito Data Management System Galápagos

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

---

## [1.0.0] — 2026-11-16

### Añadido

- Lanzamiento inicial de la versión Galápagos.
- Carga y validación de archivos Excel de ovitrampas con auto-detección de columnas.
- Tablero con indicadores clave: ovitrampas instaladas, recuperadas, positividad y total de huevos.
- Gráficos interactivos para análisis temporal y por sector.
- Mapa interactivo con agrupamiento (clusters) y mapa de calor.
- Soporte para múltiples localidades (Bellavista / Miramar).
- Historial de datasets guardados localmente.
- Gestión de usuarios y roles (admin / analista / visor).
- Datos precargados de Galápagos 2025–2026.
- Exportación de reportes a PDF.
